# Propósito : Abreviaturas que NO cierran oración en el análisis léxico

#             escriben; la comparación no distingue mayúsculas.

# LISTA PROPIA DEL PROYECTO. El apéndice de abreviaturas del Diccionario
# panhispánico de dudas, que era la fuente prevista, ya no está en línea:
# lema.rae.es/dpd/apendices/apendice2.html redirige a la portada del DPD.
# Se completa a medida que aparezcan casos.
#
# QUÉ HACE FALTA LISTAR Y QUÉ NO
# El script corta una oración después de . ? ! o … SOLO si la palabra que
# sigue empieza con mayúscula (admite antes ¿ ¡ « “ ( [ —). Por eso NO hace
# falta listar:
#   - las que van seguidas de número o de minúscula: p. 23, vol. 3, núm. 4,
#     a. C., p. ej.;
#   - las iniciales de una letra (J. L. Borges): las reconoce solo.
# Hace falta listar las que suelen ir seguidas de MAYÚSCULA: tratamientos
# delante de un nombre y remisiones bibliográficas delante de un autor.
# «etc.» NO se lista a propósito: al final de oración su punto es también
# el punto de cierre, y la oración siguiente empieza con mayúscula.
# ============================================================
