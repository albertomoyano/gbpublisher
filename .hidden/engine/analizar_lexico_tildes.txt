# ============================================================
# Archivo   : analizar_lexico_tildes.txt
# Propósito : Lista cerrada de las variantes de tilde que informa el análisis
#             léxico (engine/analizar_lexico.pl). NO se infieren por quitar
#             tildes: en castellano la mayoría de los pares que difieren solo
#             por la tilde son palabras distintas y correctas (como/cómo,
#             el/él, cambio/cambió). Solo entran las que la RAE dejó a
#             elección o suprimió.
# Formato   : tipo <TAB> forma sin tilde <TAB> forma con tilde
#             opcional  — se informa si en el proyecto aparecen las DOS formas
#             suprimida — se informa toda aparición de la forma con tilde
# Fuentes   : RAE, Libro de estilo de la lengua española, «Acentuación»,
#             punto 7: «se recomienda no tildar estos elementos nunca, si
#             bien la tilde se admite si hay riesgo de ambigüedad» (adverbio
#             solo; este, ese, aquel y sus derivados) y «nunca deben tildarse
#             esto, eso y aquello».
#             https://www.rae.es/libro-estilo-lengua-española/acentuación
#             RAE, Ortografía (2010), 3.4.2.1.1, Diptongos ortográficos:
#             estas palabras «se escribirán obligatoriamente sin tilde», «sin
#             que resulten admisibles, como establecía la Ortografía de 1999,
#             las grafías con tilde».
#             https://www.rae.es/ortografía/palabras-con-diptongo
#             De esa lista entran solo las formas cuya grafía con tilde no
#             coincide con otra palabra correcta (por eso no está «río»).
# ============================================================
